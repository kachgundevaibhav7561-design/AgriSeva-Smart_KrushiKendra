# CSS Structure

Each page now has its own CSS file:

- `css/index.css` - Home page
- `css/about.css` - About page
- `css/services.css` - Services page
- `css/contact.css` - Contact page
- `css/crops.css` - Crops page
- `css/fertilizers.css` - Fertilizers page
- `css/seeds.css` - Seeds page

The same professional header and footer colour rules are included in every page CSS file so each page keeps the same deep-green header/footer theme without depending on `shared.css`.
